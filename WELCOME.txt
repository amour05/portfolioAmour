⚙️ TECHNICAL WORKFLOW:

   Local Process:
   ┌─────────────────────────────────┐
   │ 1. npm run build                │  Build Vite (CSS/JS)
   ├─────────────────────────────────┤
   │ 2. php artisan serve            │  Start Laravel server
   ├─────────────────────────────────┤
   │ 3. Script scrapes each route    │  GET / → saves HTML
   │    via HTTP calls               │  GET /projects → saves HTML
   │                                 │  GET /blog/{slug} → saves HTML
   ├─────────────────────────────────┤
   │ 4. Copy public/ assets          │  Copy images/, build/
   ├─────────────────────────────────┤
   │ 5. Result in dist/              │  dist/index.html
   │                                 │  dist/projects/index.html
   └─────────────────────────────────┘
            ↓
   GitHub Actions (Automated):
   ┌─────────────────────────────────┐
   │ Repeat same process on          │
   │ GitHub runner (Ubuntu VM)       │
   └─────────────────────────────────┘
            ↓
   Deploy dist/ to gh-pages branch
            ↓
   GitHub Pages serves static files

🔧 COMMANDS REFERENCE:

   npm run dev
   → Local development (Vite hot reload)
   
   npm run build
   → Build Vite assets only (public/build/)
   
   npm run build:static
   → Full build: Vite + generate static + copy assets
   → This creates dist/
   
   php artisan serve
   → Start Laravel dev server
   
   php artisan static:generate --output=dist
   → Generate static pages (server must be running)
   
   php artisan migrate --database=sqlite
   → Setup SQLite database
   
   ./scripts/quick-start.bat (Windows)
   → Interactive menu helper

❓ QUICK FAQ:

   Q: Do I need a server?
   A: No! GitHub Pages is the server. Completely free.
   
   Q: Will my admin routes work?
   A: No. Only public pages generate. Admin needs backend.
   
   Q: Can I use a custom domain?
   A: Yes! Setup DNS CNAME, update GitHub Pages settings.
   
   Q: What about the database?
   A: Uses SQLite locally. Only for generation.
   
   Q: How often does it update?
   A: Every time you push. Typically 2-3 minutes.
   
   Q: Can I preview before deployment?
   A: Yes! npm run build:static creates dist/ locally.
