🚀 3 ÉTAPES POUR DÉPLOYER
───────────────────────────

ÉTAPE 1 - SETUP LOCAL (2 minutes)
──────────────────────────────────

  Windows (recommandé):
  $ cd scripts
  $ quick-start.bat
  # Sélectionner "1) SETUP INITIAL"

  Ou manuellement:
  $ composer install
  $ npm install
  $ php artisan key:generate
  
  Créer la base SQLite:
  $ mkdir database
  $ type nul > database\portfolio.sqlite
  $ php artisan migrate --database=sqlite --force


ÉTAPE 2 - BUILD LOCAL (1 minute)
────────────────────────────────

  $ npm run build:static

  ✅ Cela crée le dossier dist/ avec:
     ├─ index.html
     ├─ projects/index.html
     ├─ about/index.html
     ├─ skills/index.html
     ├─ contact/index.html
     ├─ blog/index.html
     ├─ blog/{slug}/index.html
     ├─ build/ (CSS/JS compilés)
     └─ images/ (copiées)


ÉTAPE 3 - DÉPLOYER (2 minutes)
──────────────────────────────

  $ git add .
  $ git commit -m "Deploy to GitHub Pages"
  $ git push origin main

  ✅ Le workflow GitHub Actions démarre automatiquement!
  ✅ Votre site sera en ligne dans 2-3 minutes
  ✅ Visitez: https://USERNAME.github.io/REPO-NAME/

⚙️ COMMENT ÇA MARCHE?
─────────────────────

  LOCALEMENT:
  1. npm run build:static
     ├─ Compile les assets Vite (CSS/JS)
     ├─ Lance le serveur Laravel
     ├─ Scrape les routes publiques via HTTP
     ├─ Sauvegarde le HTML rendu
     └─ Crée le dossier dist/

  SUR GITHUB:
  1. Push vers main/master
  2. GitHub Actions workflow démarre
  3. Même processus qu'en local, mais automatisé
  4. Déploie vers la branche gh-pages
  5. GitHub Pages sert le contenu statique
  6. Votre portfolio est en ligne! 🎉
